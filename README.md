# Daily Study Routine

## 3–4 Hours Per Day

### 1. Learning — 45 minutes

- Watch the assigned video/course
- Read the relevant documentation
- Take short notes

### 2. Hands-on — 90 minutes

- Write code
- Build the assigned feature
- Troubleshoot errors
- Commit your work to GitHub

### 3. Job Applications — 45 minutes

- Apply to relevant DevOps roles
- Apply to AWS/Cloud roles
- Apply to Platform Engineering roles
- Apply selectively to AI Platform/MLOps roles
- Contact recruiters/referrals

### 4. Revision — 30 minutes

Ask yourself:

- What did I learn today?
- Why is this technology needed?
- How does it work?
- How would I explain it in an interview?
- What problem did I solve today?

# Career Positioning

**Python Backend + AWS + DevOps + Kubernetes + GenAI/LLMOps**

The objective is NOT to become a pure AI/ML researcher.

The objective is to become an engineer who can:

> Build a Python application → integrate AI → containerize it → deploy it to AWS → automate it with CI/CD → run it on Kubernetes → monitor it → evaluate the LLM → troubleshoot it.

That combination is the core of this 60-day roadmap.
